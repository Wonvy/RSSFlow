# RSSFlow

[English](README.md) | **简体中文**

**任意网页，点一下就变成 RSS；点一下就能去掉广告。**

RSSFlow 是一个浏览器扩展加一个小服务端，主要有两个功能：

1. **网页 → RSS**：很多网站没有 RSS。装上扩展，在列表里随便点一条，就能拿到订阅链接，放进任何 RSS 阅读器；做好的规则还能分享给别人。
2. **隐藏 / 修改网页元素**：点一下广告或其它碍眼的元素，可以隐藏、模糊、变淡，或者像浏览器开发者工具那样修改样式。规则按网站保存，下次打开自动生效。

整个过程不需要懂 CSS、接口或 JSON。界面支持简体中文和英文。

```
[浏览器扩展：点选列表，生成规则] → [服务端：定时抓取，输出 RSS] → 任意 RSS 阅读器
                                         ↓
                                [规则市场：分享 / 一键复用]
```

## 功能

### 网页 → RSS

- **点一下认出整个列表**：自动找出同类条目，并识别标题、链接、时间、图片、摘要和作者。
  - 点到广告卡上，或者点在卡片之间的空隙里，也能认出正确的列表；
  - 瀑布流把一个列表拆成好几个容器时，会自动合并；
  - CSS Modules 这类带哈希的类名（如 `Kx7pQa_title`）会转成不随网站发版变化的选择器（`[class*="_title"]`）；
  - 猜错了可以手动重选字段，也可以扩大或缩小识别范围。
- **找回没有 `<a>` 的链接**：很多卡片靠 JS 跳转，DOM 里只有作者主页链接。RSSFlow 会排除作者和头像链接，再到页面内嵌的数据（JSON、Next.js flight data 等）里按标题找回详情页地址。同一个列表里混着多种内容（比如作品和文章）也能处理。
- **接口嗅探**：选取时自动监听网页发出的数据请求（fetch / XHR）。如果某个 JSON 接口里的内容和你点选的列表对得上，就直接改用这个接口：更稳定、更省资源，通常还能拿到网页上看不到的精确发布时间。
  - 字段（标题、链接、时间、图片、摘要、作者、分类）会自动对应；
  - 翻页参数会改回第 1 页；
  - 接口地址里的个人凭证（token、sign 等）会在保存前去掉，分享规则时不会泄露登录状态；
  - 网页没有时间时，点「帮我找数据接口」，扩展会自动点一下「下一页 / 加载更多」来发现接口；
  - 接口失效时，服务端会自动改回解析网页。
- **支持动态网页**：服务端的抓取顺序是：数据接口 → 静态抓取 → 无头浏览器渲染（Playwright），全程自动完成。
- **没有发布时间也能正确排序**：服务端会记住每条内容第一次被抓到的时间，作为发布时间。
- **中英文时间都能解析**：`2026年11月17日`、`3小时前`、`昨天 08:00`、`Nov 15, 2026`、ISO 格式等，并按网站所在时区处理（根据域名和页面语言推断）。
- **识别反爬验证页**：遇到滑块验证码、Cloudflare 这类验证页时，会明确提示原因，并继续保留上次抓到的内容。RSSFlow **不会**尝试绕过验证码。
- **图片防盗链**：RSS 里的图片带上 `referrerpolicy="no-referrer"`，减少因防盗链导致的裂图。
- **分享**：公开的规则会出现在「规则市场」，别人可以一键复制 RSS 链接，或者下载规则 JSON。
- **输出 RSS 2.0 和 JSON Feed**，包含 `dc:creator` 和 `category`；服务端自带缓存、限流和内网地址防护（SSRF）。

### 隐藏 / 修改网页元素（去广告）

- **点一下就能预览**：点扩展图标里的「隐藏 / 修改网页元素」，然后在网页上点一下广告，马上就能看到效果，满意了再保存。
- **快速处理**：隐藏、模糊、变淡；范围可以是「只这一个」或「所有同类」。
- **自动选中整张卡片**：如果点中的只是卡片里的一行字或一张图，会自动选中整张卡片，隐藏后不留空白格子。「所有同类」会生成「装着这种广告的格子」这样的规则，不会把所有格子都隐藏。
- **样式编辑**：像浏览器开发者工具一样查看和修改选中的元素，改动即时预览：
  - 网页上给选中的元素画蓝框，标出标签名和尺寸，例如 `div.card · 320 × 240`；
  - 层级导航（`… › div.grid › div.slot › article`），点哪一层就选中哪一层；
  - 盒模型图：外边距、边框、内边距四个方向的数值都能直接改；
  - 常用属性按布局、文字、背景与边框、效果分组：颜色用取色器，字号、圆角、不透明度用滑块；填纯数字会自动补上 `px`；
  - 元素属性，以及全部计算样式（几百条，可以搜索、可以修改）；
  - 改过的项会高亮，可以单项或全部重置；也可以直接编辑生成的 CSS 文本。
- **鼠标悬停时显示原样**：平时按规则处理，鼠标移上去就显示原来的内容，移开后恢复。
- **下次打开自动生效**：规则按网站保存在浏览器里，`styles.js`（约 4KB）会在网页刚开始加载时就注入 CSS，广告不会先闪一下再消失；后来动态加载的元素同样生效。
- **按网站申请权限**：第一次在某个网站使用时，浏览器才会询问是否允许 RSSFlow 修改这个网站，不会在安装时就要求访问所有网站。
- **可管理**：在弹窗或面板里可以暂停某个网站的全部规则，也可以逐条开关、删除。
- **安全**：选择器和自定义样式都会检查，不能跳出规则，也不能加载外部资源（`url()`、`@import` 等会被去掉）。

### 通用

- **面板可以拖动**：按住面板顶部的标题栏（⋮⋮ 处）拖到任意位置，松开后会记住；面板不会被拖出屏幕；点「⇆」回到默认位置。
- **暂停选取**：需要先操作网页（关弹窗、翻页）时，点面板右上角的「暂停」。
- **多语言**：扩展、网页、错误提示都支持中文和英文，可以按[下面的方法](#添加一种新语言)添加新语言。

## 快速开始

需要 Node.js 22.13 或更新版本（推荐 24）。

```bash
npm install
```

```bash
npx playwright install chromium
```

```bash
npm run dev
```

服务启动在 http://localhost:8787 。开发模式下附带几个示例页面：

| 页面 | 演示什么 |
|---|---|
| `/demo/news.html` | 普通的静态新闻列表 |
| `/demo/dynamic.html` | 内容由 JavaScript 加载 |
| `/demo/card-feed.html` | 设计社区式的卡片流：哈希类名、广告卡、链接只存在于页面数据里 |
| `/demo/api-feed.html` | 卡片通过数据接口加载、带「加载更多」（加 `?ssr=1` 模拟第一页写在网页里的情况） |

### 安装浏览器扩展

1. 打开 `chrome://extensions`（Edge 打开 `edge://extensions`），开启「开发者模式」；
2. 点「加载已解压的扩展程序」，选择 `packages/extension/dist` 目录；
3. 打开任意网页，点工具栏上的 RSSFlow 图标：
   - **生成 RSS**：点「在当前页面选取列表」（或按 `Alt+Shift+R`），在列表里点一条内容，确认预览后点「生成 RSS 订阅链接」；
   - **去广告**：点「隐藏 / 修改网页元素」，允许 RSSFlow 修改这个网站，然后点一下要处理的元素。

扩展默认连接 `http://localhost:8787`，可以在弹窗底部改成你自己部署的服务器地址。修改代码后运行 `npm run build:ext`，再在扩展管理页点「重新加载」。

## 项目结构与常用命令

| 目录 | 说明 |
|---|---|
| `packages/core` | 共享核心：列表识别、字段提取、接口匹配、时间解析、样式规则、规则校验、多语言。浏览器和服务端共用同一套代码 |
| `packages/server` | 服务端：API、静态/动态抓取、RSS 输出、规则市场页面。使用 Node 内置的 SQLite，没有原生依赖 |
| `packages/extension` | 浏览器扩展（Manifest V3）：选取面板、样式面板、网络嗅探、弹窗、后台脚本 |

| 命令 | 作用 |
|---|---|
| `npm run dev` | 构建扩展，然后启动开发服务器（文件改动后自动重启） |
| `npm start` | 以生产方式启动服务端 |
| `npm run build:ext` | 构建扩展到 `packages/extension/dist` |
| `npm test` | 运行测试（核心算法 + 服务端端到端，包括动态渲染） |
| `npm run typecheck` | TypeScript 类型检查 |

## 开发工具

**服务器视角页面**（仅开发模式）：在浏览器里打开下面的地址，可以看到服务器静态抓到的网页，选取面板会自动注入。网页原有的脚本被禁用了，但脚本里的数据保留着。在网址末尾加 `#rssflow=style` 会打开样式面板。

```
http://localhost:8787/dev/view?url=https://example.com/
```

**try-site 脚本**：用无头浏览器打开网页、注入选取面板、点击指定的条目，打印识别结果并截图。

```bash
node packages/server/scripts/try-site.ts https://example.com/news "某条新闻标题里的一段文字"
```

- 第二个参数可以是条目里的一段文字，也可以写成 `css:选择器`（适合每次打开内容都不一样的推荐流）；
- `--via-server`：通过服务器视角页面打开，适合会拦截无头浏览器的网站；
- `--create`：同时让本地服务器保存规则，并打印服务器的抓取结果；
- `--scroll N`：先向下滚动 N 屏，用于无限滚动的页面。

**try-detail 脚本**：测试某个详情页（内容页）能抽出什么，并生成一个预览网页。

```bash
node packages/server/scripts/try-detail.ts "https://example.com/article/123"
```

```bash
node packages/server/scripts/try-detail.ts ~/Downloads/page.html --url "https://example.com/article/123"
```

- 传网址：用服务器同样的方式去抓，遇到反爬挑战会直接提示；
- 传本地文件：在浏览器里「另存为 → 网页，仅 HTML」，然后离线测试。用 `--url` 告诉脚本原网址，图片和链接才能补全。

## 部署配置（环境变量）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` / `HOST` | `8787` / `127.0.0.1` | 监听地址；对外提供服务时把 `HOST` 设为 `0.0.0.0` |
| `RSSFLOW_PUBLIC_URL` | 按请求推断 | 对外访问地址，用来生成订阅链接，例如 `https://rss.example.com` |
| `RSSFLOW_DATA_DIR` | `./data` | SQLite 数据库所在目录 |
| `RSSFLOW_ALLOW_PRIVATE` | 关闭 | 是否允许抓取内网地址。公共实例**不要**开启 |
| `RSSFLOW_MIN_REFRESH` | `10` | 最短刷新间隔（分钟） |
| `RSSFLOW_RENDER_CONCURRENCY` | `2` | 同时运行的浏览器渲染任务数 |
| `RSSFLOW_WRITE_RATE` | `30` | 每个 IP 每分钟允许的写请求数 |
| `ANTHROPIC_API_KEY` | 未设置 | AI 摘要用（见[暂时搁置的功能](#暂时搁置的功能)） |
| `RSSFLOW_AI` / `RSSFLOW_AI_MODEL` / `RSSFLOW_AI_MAX_PER_HOUR` | 自动 / `claude-opus-5-5` / `200` | AI 摘要的开关、模型和每小时上限 |

## 规则格式

```json
{
  "version": 1,
  "name": "示例新闻",
  "url": "https://news.example.com/list",
  "mode": "auto",
  "itemSelector": "li.news-item",
  "fields": {
    "title":   { "selector": "h3" },
    "link":    { "selector": "h3 > a", "attr": "href" },
    "date":    { "selector": "span.time" },
    "image":   { "selector": "img", "attr": "src" },
    "summary": { "selector": "p.desc" },
    "author":  { "selector": "span.author" }
  },
  "refreshMinutes": 60,
  "utcOffset": 480
}
```

- `mode`：`auto`（有数据接口时先用接口，再静态抓取，最后浏览器渲染）、`static`、`render` 或 `api`（只用接口）。
- `selector` 相对于条目元素；空字符串表示条目元素本身。
- `attr` 不填表示取文本；`href` 和 `src` 会自动转成绝对地址，`src` 还兼容 `data-src` 等懒加载写法。
- 链接也可以来自页面数据：`"link": { "selector": "", "from": "data", "prefixes": ["https://example.com/work/", "https://example.com/article/"] }`，表示在页面内嵌数据里，找每条标题后面第一个以这些前缀开头的网址。
- `api`（可选）：数据接口。`listPath` 是列表在 JSON 里的路径；`fields` 里每个字段是一个模板，`{content.title}` 表示取这个路径上的值，也可以拼成网址，比如 `https://example.com/p/{slug}.html`；`tags` 可以写多个，用逗号分隔。

```json
"api": {
  "url": "https://example.com/api/feed?page=1&size=20",
  "method": "GET",
  "listPath": "data.list",
  "fields": {
    "title": "{title}",
    "link": "{url}",
    "date": "{published_at}",
    "image": "{cover}",
    "author": "{author.name}",
    "tags": "{category},{sub_category}"
  }
}
```

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/health` | 服务状态 |
| `POST` | `/api/preview` | `{ recipe }` → 试抓，不保存 |
| `POST` | `/api/recipes` | `{ recipe, public }` → 保存规则，返回订阅链接和 `editToken` |
| `GET` | `/api/recipes?q=` | 公开规则列表 |
| `GET` | `/api/recipes/:id` | 规则详情（加 `?download=1` 下载 JSON） |
| `PUT` / `DELETE` | `/api/recipes/:id` | 修改或删除，需要请求头 `x-edit-token` |
| `GET` | `/feed/:id.xml` / `/feed/:id.json` | RSS 2.0 / JSON Feed |

错误信息会按 `Accept-Language` 请求头或 `?lang=` 参数返回对应语言，格式为 `{ "error": "...", "code": "err.xxx" }`。

## 添加一种新语言

1. 把 `packages/core/src/i18n/en.ts` 复制为新文件，比如 `ja.ts`，翻译里面的文案。可以只翻一部分，没翻的会自动回退到英文。
2. 在 `packages/core/src/i18n/index.ts` 的 `LOCALES` 里加一行：`ja: { name: '日本語', messages: ja }`。
3. 如果希望扩展商店页面也显示这种语言，再加上 `packages/extension/public/_locales/ja/messages.json`。

扩展弹窗、选取面板、规则市场页面和 API 错误信息都会自动支持新语言。语言的选择顺序：用户手动选的 > 浏览器语言 > 英文。

## 已知限制

- 推荐流是个性化的，每次抓到的内容不完全一样；订阅里看到的是服务器（未登录访客）视角的内容。
- 需要登录才能看到的内容抓不到。遇到验证码的网站会提示原因，但不会去绕过。
- 需要登录态或请求签名的数据接口无法在服务器上使用（凭证会被去掉），这时会自动改回解析网页。
- 接口嗅探只能看到选取面板打开之后的请求，以及之前已经发出的 GET 请求。之前发出的 POST 请求（比如 GraphQL）需要在面板打开后再触发一次，例如翻页。
- 有防盗链的图片，在少数会改写 HTML 的 RSS 阅读器里仍然可能显示不出来。

## 暂时搁置的功能

下面这些功能的代码和测试都还在，但选取面板里已经隐藏。恢复方法：把 `packages/extension/src/content.ts` 里的 `DETAIL_FEATURE` 改成 `true`，然后重新构建扩展。

- **详情页**：打开每条内容的详情页，补充摘要、正文、作者、标签和准确的发布时间；以图片为主的页面会按顺序抽出全部内容图。详情页按网址缓存，每次刷新最多抓 15 个新页面；遇到反爬挑战的那一类网址会自动跳过。
- **AI 摘要**：服务端配置 Anthropic 凭证（`ANTHROPIC_API_KEY`）后，可以用 Claude 根据详情页正文写 2–3 句摘要。每个链接只生成一次，有每小时调用上限；网页正文一律当作待总结的材料，不会执行其中的指令。
- 已知问题：有些页面的摘要和图片地址里会出现没解码的 `&amp;`，恢复时需要先修。
